# Matched Meshopt task-shape corpus

This directory contains deterministic synthetic glTF assets for measuring
Meshopt task granularity through `Model.fromGltfAsync`. Each fixture uses 200
primitives and exactly 9,540 compressed attribute bytes, while the number of
unique compressed buffer views varies across 1, 10, 60, and 200.

The assets are generated by
[`createMeshoptTaskShapeCorpus.mjs`](../../../../../Tools/benchmark/decompression/createMeshoptTaskShapeCorpus.mjs).
`manifest.json` records the exact encoder version, generator hash, file hashes,
decoded-byte construction, and per-fixture shape. The source data is synthetic
and has no external asset license or attribution.
