# SPZ benchmark assets

These GLBs are reproducible wrappers around real, versioned SPZ files. The
compressed SPZ bytes are embedded unchanged in the
`KHR_gaussian_splatting_compression_spz_2` buffer view. The accompanying
one-tile tileset manifests load them through the supported public
`Cesium3DTileset.fromUrl` Gaussian-splat path.

The wrappers were generated by
[`Tools/benchmark/decompression/createSpzGlb.mjs`](../../../../../Tools/benchmark/decompression/createSpzGlb.mjs).
The original source hashes, wrapper hashes, source commits, and licensing
information are recorded in `manifest.json`.

| Asset                  | Source             | Compressed bytes | Gaussian splats | SPZ version |
| ---------------------- | ------------------ | ---------------: | --------------: | ----------: |
| `hornedlizard.spz.glb` | `nianticlabs/spz`  |       18,143,098 |         786,233 |           2 |
| `racoonfamily.spz.glb` | `nianticlabs/spz`  |       24,202,962 |         932,560 |           2 |
| `innenstadt.spz.glb`   | `gkvoelkl/js-3dgs` |       15,928,789 |         683,344 |           2 |

The source repositories are MIT-licensed at the pinned commits. Their
license and README files are retained under `provenance/`.

The current `Model.fromGltfAsync` path does not consume the postprocessed SPZ
typed-array attributes as render buffers, so these assets are not advertised
as Model API fixtures.
